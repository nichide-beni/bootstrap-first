# Bootstrap5フレームワークについて学ぼう

フレームワークとは、開発をするための製作キットのようなもの。  
Bootstrapでは、HTML/CSS/JavaScriptで構成されている。  
勢いは後発のフレームワークに押され気味ではあるが、安定した人気と長い運用実績がある。  

## サンプル一覧をダウンロードして実行してみよう

以下のURLからダウンロードする。  
https://getbootstrap.jp/docs/5.3/examples/  

次のサンプルを動かしてみよう。  

- album
- blog
- buttons
- carousel (js)
- grid
 - デバイスサイズを変えながらグリッドの動きを見てみよう
- modals (js)

## 例題を動かしてみよう

### sample01 グリッドの使用例を動かしてみよう

featuresのサンプルからグリッド部分を抜き出して、mdの処理を加えている。  
ウィンドウを伸縮させ動作を確認してみよう。

## 演習をやってみよう

### example01 albumからコピーしたファイルを以下のようにカスタマイズしよう

- Viewボタンを青系に変更
- Editを緑系に変更
 - ドキュメントのカラーを確認
- データをコピーしてアイテムを4つ追加しよう(合計12)
 - 1列, 2列, 3列, 4列と12の約数で構成されるため
- 最大サイズの時に4列にしよう

### example02 モーダルのドキュメントから該当する方法を探してみよう

Bootstrapのドキュメントから、ディレクトリにある画像ファイルと同じ結果になるようなソースを探して記述してみよう。  

### example03 複数のモーダルを操作しよう

前演習と同じように、ディレクトリにある画像のようになるようコードを作成してみよう。  
プラン別にボタンのカラーリングが別のモーダルを開くようになっている。
